# Contributors

## How this project was made

**Singularvs** is a human-AI development experiment. The idea, the creative direction, the design decisions, the testing and the final validation were conducted by a human. Much of the code was written in collaboration with a language model. It is an example of **vibecoding**: programming guided by intuition, curiosity and conversation, rather than formal specification.

## Author and creative direction

**Cesar** — Conception, design direction, architecture of ideas, testing, iterative feedback and validation.

Responsible for:

- The project vision: a 2D demake of SpaceEngine with an Elite (1984)-style procedural methodology.
- All scope, priority and cut decisions.
- Description of bugs, expected behavior and improvement suggestions in each cycle.
- Manual browser testing and verification of each patch.
- Curation of scientific sources and external references.
- The choice of the MIT license and the decision to publish in the open domain.

## Development in collaboration with AI

### DeepSeek

Language model from DeepSeek that **wrote most of the source code** of this project in direct collaboration with the author.

- Code generation from natural language descriptions.
- Algorithm proposal (procedural generation of galaxies, star systems, planets, tectonics, biology).
- Refactorings, bug fixes and incremental patch implementation.
- Architecture and code organization suggestions.
- Review of its own code in subsequent cycles.

According to the DeepSeek Terms of Use (Section 4.2), all rights to the *Outputs* (the generated code) are assigned to the user, and use for developing derivative products is explicitly permitted.

## References and inspirations

Projects and works that conceptually influenced Singularvs, without code or asset contribution:

- **SpaceEngine** (Vladimir Romanyuk / CosmoGraphic) — conceptual and aesthetic inspiration.
- **Elite** (David Braben and Ian Bell, 1984) — inspiration in the procedural philosophy.
- **Kurzgesagt - In a Nutshell** — conceptual scientific references.

## Note on AI code generation

This project is transparent about its use of AI. A substantial portion of the code was generated by language models under human supervision, direction and testing. The MIT license is granted by the human author of the project, who has the right to do so according to the terms of the tools used.
